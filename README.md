# FPGA-Based 8-Bit Arithmetic Logic Unit (ALU)

## Project Overview

Designed and implemented an 8-bit Arithmetic Logic Unit (ALU) using VHDL on an Altera FPGA development board. The project demonstrates fundamental digital system design principles, including arithmetic and logic operations, control circuitry, register-based data storage, and hardware interfacing.

The design was developed using Intel Quartus and evaluated through simulation and hardware testing.

## Key Features

- **8-Bit ALU:** Processes 8-bit input operands using digital arithmetic and logic circuitry.
- **VHDL Implementation:** Describes the digital hardware architecture using a hardware description language.
- **Control Logic:** Selects operations through control signals.
- **Register Storage:** Incorporates registers for storing digital values.
- **Seven-Segment Display:** Interfaces with the FPGA board to display output information.
- **Simulation and Verification:** Uses Intel Quartus development tools for design validation.

## Technologies Used

- **Hardware:** Altera FPGA Development Board
- **Hardware Description Language:** VHDL
- **Development Environment:** Intel Quartus
- **Engineering Concepts:** Digital Logic Design, RTL Design, Combinational Logic, Sequential Logic, FPGA Development

## Design and Implementation

1. Developed VHDL modules representing the ALU's digital logic.
2. Implemented control circuitry to select ALU operations.
3. Integrated register-based storage and output display functionality.
4. Compiled the design using Intel Quartus.
5. Performed simulations to evaluate functional behaviour.
6. Tested the design using FPGA hardware.

## Results

The project provided practical experience in FPGA-based digital system development, VHDL programming, digital circuit integration, and hardware verification.
